## Pixel-Level Findings

### Shared Canvas Chrome

- Coze keeps Workflow authoring on a full-page canvas route, not a nested page card.
- Header is compact: back action, flow icon/name, info/edit icons, autosave state, utility icons, `发布`, and more menu.
- No top product banner is visible in the current reference. Hify should not reserve vertical space for one.
- Canvas background is a light dotted grid. Nodes float directly on the grid.

### Node Cards

- Node cards are compact white rounded rectangles with subtle shadow/border.
- Ports are circular purple endpoints attached outside the card edge.
- START variable chips stay on one line until width would overflow, then show a trailing `...`.
- The selected node outline is purple. Selecting LLM opens the right config panel and keeps the selected card visible on the canvas.
- The LLM card header has a run triangle and more menu. The card summary shows inputs, outputs, model, and skill state.

### Right Config Panel

- Selecting the LLM node opens a fixed right panel.
- The panel header includes icon, title, run triangle, more menu, and close.
- Visible sections include mode (`单次`/`批处理`), model dropdown with gear, skill empty state with add button, input rows with `会话历史` toggle, visual-understanding input, system prompt, and user prompt.
- The right panel coexists with the centered bottom toolbar.

### Bottom Toolbar And Debug

- The bottom toolbar is centered and compact.
- Visible controls are panel/menu, zoom dropdown, utility icons, prominent `+ 添加节点`, `角色`, wrench/debug, and green `试运行`.
- The current reference does not expose an operation-mode toggle. Hify intentionally keeps this as a product override: the bottom toolbar must show a visible operation-mode icon button, not visible mode-name text. The button exposes `触控板模式` / `鼠标模式` through tooltip/aria label, and clicking it must switch the canvas control mode.
- Trial/debug state appears as a bottom dock titled `调试`, with run tree on the left and `详情` flamegraph on the right.
- The bottom debug panel has a close action and a sticky green action `保存并开始对话调试`.

### Add-Node Menu

The live add-node popover opens from the bottom toolbar and includes search plus grouped two-column node entries:

- `大模型`, `插件`, `工作流`
- `代码`, `选择器`, `意图识别`, `循环`, `批处理`, `变量聚合`, `异步任务`
- `输入`, `输出`
- `SQL自定义`, `新增数据`, `更新数据`, `查询数据`, `删除数据`
- `知识库写入`, `知识库检索`

Hify can expose only runtime-backed nodes as enabled. Future or unsupported nodes must be hidden, disabled, or clearly tagged as later-stage.
