# 114 Resource Invocation Nodes Reference

- AgentArts Agent node: system variables include conversation history/current time/user id/conversation id/dialogue count; Agent node has input, plugin binding, prompt/tool constraints, termination conditions, and output as the final model reply. Source: https://support.huaweicloud.com/usermanual-agentarts0/agentarts_05_0064.html
- AgentArts plugin node: plugin input/output parameter structure is imported from plugin metadata; node config assigns each input parameter value by reference or literal input; output parameters are imported and not edited in the node; exception policy supports timeout, retry, interruption/fallback/exception branch. Source: https://support.huaweicloud.com/usermanual-agentarts0/agentarts_05_0072.html
- Coze Studio workflow runtime: nodes are typed units in a DAG; control flow depends on edge success/skip, data flow comes from mapped predecessor outputs plus static/variable values; Invoke takes input and returns output maps. Source: https://github.com/coze-dev/coze-studio/wiki/11.-%E6%96%B0%E5%A2%9E%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%8A%82%E7%82%B9%E7%B1%BB%E5%9E%8B%EF%BC%88%E5%90%8E%E7%AB%AF%EF%BC%89
